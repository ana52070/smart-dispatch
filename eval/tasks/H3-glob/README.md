# 任务 H3：glob 路径匹配

`src/glob.js` 现在只是把 `*` 换成 `.*` 的粗糙实现。请按下面的规格重写 `match(pattern, path, options)`，返回布尔值。

```js
import { match } from './src/glob.js'
match('src/**/*.js', 'src/a/b.js')            // true
match('*.md', '.github.md')                    // false（点文件规则）
match('*.md', '.github.md', { dot: true })     // true
```

`options`：`{ dot = false, nocase = false }`。

## 段

- 模式和路径都按 `/` 切成段，逐段匹配。段数必须对应（`**` 除外，见下文）。因此开头的 `/`、末尾的 `/` 都有意义：`/a` 只匹配 `/a`，`a/` 只匹配 `a/`。
- 空模式只匹配空路径。

## 段内语法

- `*`：匹配段内任意长度（包括 0）的字符，不会跨越 `/`。连续多个 `*` 出现在段内（不是整段 `**`）时，与单个 `*` 相同。
- `?`：匹配段内恰好一个字符。
- `[...]`：字符类，匹配段内一个字符。
  - 可以列出字符（`[abc]`），也可以写范围（`[a-z0-9]`）。
  - `[!...]` 或 `[^...]` 表示取反。
  - 紧跟在 `[`、`[!` 或 `[^` 之后的 `]` 是普通字符（`[]a]` 匹配 `]` 或 `a`）。
  - `-` 出现在类的开头或结尾时是普通字符。
  - 类中可以用 `\` 转义任何字符。
  - 没有闭合的 `[` 是普通字符 `[`。
- `\x`：匹配字符 `x` 本身，`x` 可以是任何特殊字符（`\*`、`\?`、`\[`、`\{`、`\,`、`\\` 等）。模式末尾单独的 `\` 匹配一个 `\`。
- 其他字符按字面匹配。

## 花括号展开

在切段之前先展开花括号：

- `{a,b,c}` 展开为多个候选模式，路径匹配任意一个候选即可。
- 可以嵌套（`{a,{b,c}d}` → `a`、`bd`、`cd`），可以有空选项（`x{,y}` → `x`、`xy`），可以并列做笛卡尔积（`{a,b}{1,2}` → `a1 a2 b1 b2`），选项中可以包含 `/` 和 `**`。
- 只有包含至少一个顶层逗号的花括号组才会展开；`{a}`、`{}` 按字面匹配。
- 没有闭合的 `{` 按字面匹配。
- 转义的 `\{`、`\}`、`\,` 不参与展开。字符类 `[...]` 内部的 `{`、`}`、`,` 也不参与展开。

## `**`

- 只有当一整段恰好是 `**` 时才是特殊的“globstar”，匹配零个或多个完整的段：`a/**/b` 匹配 `a/b`、`a/x/b`、`a/x/y/b`；`**` 单独匹配任意路径（包括空路径）；`a/**` 匹配 `a`、`a/x`、`a/x/y`。
- 其他位置的 `**`（如 `a**b`）按段内 `*` 处理。

## 点文件规则（`dot: false` 时）

- 路径中以 `.` 开头的段，只能被**以字面 `.` 开头**的模式段匹配（`\.` 也算字面 `.`）。`*`、`?`、字符类不能匹配这类段开头的 `.`。
- globstar `**` 不能跨过以 `.` 开头的段：`a/**/b` 不匹配 `a/.x/b`，`**` 不匹配 `.git/config`。
- `dot: true` 时没有这些限制。

## 大小写

- 默认区分大小写；`nocase: true` 时字面字符和字符类都不区分大小写。
