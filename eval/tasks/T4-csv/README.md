# 任务 T4：流式 CSV 解析器

在 `src/csv.js` 中实现一个**流式** CSV 解析器。数据会被切成任意大小的块（chunk）陆续传入，切分点可能落在任何位置：引号中间、`""` 两个引号之间、`\r` 和 `\n` 之间，等等。无论怎么切分，解析结果必须和一次性传入完全相同。

## 接口

```js
import { createParser, parse, CsvError } from './src/csv.js'

const p = createParser({ delimiter: ',', onRow: (fields) => {} })
p.push(chunk)   // chunk 是字符串，可以是空字符串
p.end()         // 输入结束

parse(text, { delimiter })  // 便捷函数：返回 string[][]
```

## 规则

1. 字段之间用分隔符分隔（默认 `,`）。`delimiter` 必须是长度为 1 的字符串，且不能是 `"`、`\r`、`\n`，否则 `createParser` 抛出 `RangeError`。
2. 记录之间用 `\n`、`\r\n` 或单独的 `\r` 分隔。
3. 字段以 `"` **开头**时是引号字段：内容中的 `""` 表示一个 `"`；分隔符和换行符都作为普通内容保留。闭合引号之后只能是分隔符、换行或输入结束，否则抛出 `CsvError`。
4. 非引号字段中间出现的 `"` 按普通字符处理（`a"b` 就是 `a"b`）。字段内容不做任何去空白处理。
5. 整行为空（两个换行之间什么都没有）时跳过，不产生记录。只含 `""` 的行产生 `['']`。
6. 输入末尾有没有换行，结果都一样，末尾的换行不会产生空记录。最后一条记录以分隔符结尾时，最后一个字段为空字符串（`a,` → `['a', '']`）。
7. 整个流开头的 BOM（字符 U+FEFF）要去掉，其他位置的 BOM 保留为普通字符。
8. `end()` 时引号还没闭合，抛出 `CsvError`。
9. `CsvError` 继承 `Error`，它的 `line` 属性是出错位置所在的**物理行号**（从 1 开始，引号内的换行也计入行数）。
10. `onRow` 按顺序同步调用，每条记录一次，参数是字符串数组。
11. `end()` 之后再调用 `push` 或 `end`，抛出 `Error`。

运行 `npm test` 执行可见测试。
